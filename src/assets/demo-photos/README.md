# Demobilder

Bilder i denne mappen brukes som demobilder i appen. De er ikke sjekket inn i
repoet, fordi repoet er offentlig og bildene kan vise andres firmanavn og skilt.

Legg egne bilder her med disse filnavnene, så plukkes de opp når appen bygges:

- `hjullaster.jpg`
- `dosor.jpg`
- `kompakt.jpg`
- `tippbil-plog.jpg`
- `tippbil.jpg`

Mangler et bilde, viser appen en tegning av maskintypen i stedet.
